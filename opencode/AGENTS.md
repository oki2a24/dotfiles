# ユーザー固定指示（プロジェクトに固有のルール）

## 1. やりとりの言語
すべてのやりとりは **日本語** で行います。

## 2. コードのドキュメントコメント
- コード内のドキュメントコメント（docstring）は **日本語** で記述します。
- パブリックなクラスとメソッドについては **必ず** docstring を入れてください。
- ユニットテストのテストメソッドにも日本語の `why:` コメントを入れること。

## 3. コミットメッセージ
- **Conventional Commits** 形式で記述します（例: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:` など）。
- コミット **本文**（Body）には、**なぜそうしたか**（またはなぜそうしなかったか）を **日本語** で必ず記述してください。
